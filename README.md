# SolderedRenegade

It's a Giratina which has 2 LEDs as eyes, controlled by a switch on the back!

## Author
Vaibhav Nargwani aka [@V Play Games](https://hackclub.slack.com/team/U08RM94EECT)

## Bill of Materials
| S. No.  | Name           | Quantity |
| ------- | -------------- | -------- |
| 1       | Battery Holder | 1        |
| 2       | Push Button    | 1        |
| 3       | 5mm LED        | 2        |
| 4       | Resistor       | 6        |
